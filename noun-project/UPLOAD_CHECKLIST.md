# Noun Project 업로드 체크리스트

업로드 화면에서 확인한 규정 (2026-11 기준)

## 제출 전
- [ ] **직접 만든 아이콘인가?** (Your Work: 본인 저작물만, AI 생성 아이콘이나 AI 같은 스타일 금지. 위반하면 거절되고 계정이 정지될 수 있음)
- [ ] **새로운 아이디어인가?** (Fresh Ideas: 이미 사이트에 많은 주제는 새로운 해석을 더해야 함)
- [ ] **세트 안에서 스타일이 통일됐는가?** (Well Designed: 선 굵기, 모서리, 여백을 맞추기)

## 파일 규격
- [ ] SVG 형식
- [ ] **검은색 단색**, 흰 부분은 칠하지 말고 **투명(구멍)**으로
- [ ] 가장 긴 변이 **100px 이하**, 가장자리에 **5px 여백** 권장
- [ ] **그룹 해제**, 복합 패스(compound path)로 합치기
- [ ] **선(stroke) 없음**: 선은 모두 면으로 변환 (Illustrator: 개체 → 패스 → 윤곽선)
- [ ] 텍스트, 이미지, 그라데이션, 마스크 없음
- [ ] 검사 명령: `python3 scripts/check_svg.py <폴더>`

## 업로드 화면에서
- [ ] Upload Icons → **Icon Set**(세트) 또는 Individual Icons(개별) 선택
- [ ] 한 번에 최대 **10개**까지 올릴 수 있고, 심사 대기열에 10개가 차면 심사가 끝날 때까지 더 올릴 수 없음
- [ ] 아이콘마다 **이름(필수)**과 **태그 1~5개** 입력
- [ ] 라이선스 선택: Creative Commons(CC BY) 또는 Public Domain
- [ ] 이름은 구체적으로, 기존 아이콘과 겹치지 않게 (`1_titles_tags_sets.csv` 참고)

## 꾸준히 올리는 흐름
1. 세트 하나에 10개 기획: 주제와 들어갈 아이콘 목록
2. 직접 그리기 → 규격 검사 → 이름과 태그 정하기
3. 제출 → 심사 결과 기다리기 → 거절 사유가 있으면 기록해서 다음에 반영
4. 기다리는 동안 기존 아이콘의 제목과 태그 정리하기
