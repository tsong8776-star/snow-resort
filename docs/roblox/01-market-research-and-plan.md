## 1. 한 줄 결론

**"놀러 가는 스키장"을 "타고 → 벌고 → 모으고 → 꾸미는 스키장"으로 바꿉니다.**
지금 게임은 볼거리와 놀거리가 많지만, 로블록스 상위 게임들이 공통으로 가진 **매일 다시 올 이유(수집·성장)**가 약해요.
기존 콘텐츠(썰매, 스키점프, 빙어 낚시, 눈사람, 꾸미기 상점)는 거의 그대로 살리고, 그 위에 **눈꽃 펫 수집과 장비 성장**을 얹는 방향을 추천해요.
출시 목표는 **12월 중순, 겨울 방학과 연말 시즌**이에요.

### 2-3. 히트 게임의 공통 공식
1. **10초 안에 이해되는 핵심 반복**: 심기→기다리기→팔기, 훔치기→지키기
2. **희귀도 수집**: 일반·희귀·전설 등급, 반짝이는 변종
3. **잠깐 나가 있어도 쌓이는 성장**: 다시 접속할 이유
4. **남에게 보여 줄 거리**: 펫, 스킨, 순위표
5. **잦은 업데이트와 한정 이벤트**: 주간 한정, 시즌 아이템
6. **꾸미기는 매출 상위 게임 대부분에 들어 있어요**

## 3. 우리 게임 진단

### 강점
- 썰매, 스키점프, 빙어 낚시, 눈싸움, 눈사람, 캠프파이어, 불꽃놀이 등 **이미 콘텐츠가 풍부**
- 일일 미션, 눈꽃 코인, 꾸미기 상점, 주간 한정 아이템 → **수익 구조의 뼈대가 이미 있음**
- 이모트, 하이파이브, 2인 튜브 썰매 → **채팅 없이 함께 노는 장치**
- 순위표 3종(빙어 길이, 점프 비거리, 썰매 점수)

### 약점
- 핵심 반복이 흐림: 할 게 많지만 **"왜 계속해야 하는지"**가 약함
- 수집 요소 부족: 희귀도, 등급, 모으는 재미가 없음
- 장기 성장 없음: 장비 강화, 새 구역 해금 등이 없음
- 저장이 브라우저에만 됨 → 로블록스에선 DataStore로 계정에 저장

## 4. 방향 제안

| 안 | 내용 | 장점 | 단점 |
|---|---|---|---|
| A. 그대로 이식 | 지금 게임을 그대로 옮기고 꾸미기만 판매 | 빠름, 정체성 유지 | 재방문 약함, 매출 낮음 |
| **B. 수집·성장형 (추천)** | 타기 → 코인 → 장비 강화 + 눈꽃 펫 수집 | 히트 공식과 맞음, 기존 콘텐츠 재사용 | 펫과 밸런스 설계 필요 |
| C. 스키장 타이쿤 | 내 스키장을 짓고 운영 | 타이쿤은 검증된 장르 | 사실상 새 게임, 기간 김 |

**B안을 추천해요.** C안의 "내 오두막 꾸미기"는 출시 후 업데이트로 넣을 수 있어요.

## 5. B안 상세 설계

### 5-1. 핵심 반복 (30초~2분)
```
리프트/텔레포트로 정상 → 썰매·스키로 내려오기 (속도·트릭·게이트 = 코인)
 → 코인으로 [장비 강화] 또는 [눈꽃 구슬 열기 → 펫]
 → 펫이 코인 배수를 올려 줌 → 더 높은 슬로프 해금 → 반복
```
첫 1분: 접속하자마자 **정상에서 썰매에 탄 채로 시작** → 바로 내려오며 코인 획득 → "강화하기" 안내

### 5-2. 기존 콘텐츠 활용
| 지금 기능 | 로블록스 버전 | 비고 |
|---|---|---|
| 스키·코스·리프트 | 그대로, 코스별 해금 (초급→중급→상급→블랙) | 상급 코스일수록 코인 배수 ↑ |
| 썰매장·2인 튜브 | 핵심 콘텐츠. 썰매 등급(나무→플라스틱→레이싱→황금) | 장비 강화의 중심 |
| 스키점프 | 비거리 = 보너스 코인, 전 서버 순위표 | OrderedDataStore |
| 빙어 낚시 | **물고기 도감** (등급·크기·반짝이 변종) | 두 번째 수집 축 |
| 눈사람·눈싸움 | 그대로 (점수 없는 놀이) | 소셜 놀이 |
| 이모트·하이파이브 | 그대로, 이모트 추가 판매 | 채팅 대체 |
| 일일 미션·코인·상점 | 그대로 + 주간 미션, 연속 출석 보상 | 28일 재방문 |
| 밤·날씨·불꽃놀이 | **정해진 시간 이벤트** (매일 저녁 불꽃놀이, 눈보라 때 희귀 펫 확률 ↑) | 약속된 접속 시간 |
| NPC (코코, 부, 곰 등) | 퀘스트 안내 NPC | 튜토리얼 |
| 방문 기록 관리자 페이지 | 제거 | 로블록스 분석 도구로 대체 |
| 글 채팅 | 로블록스 기본 채팅 + **빠른 말하기 버튼** | 연령 확인 안 한 사람도 소통 |

### 5-3. 새로 넣을 것
- **눈꽃 펫**: 펭귄, 북극여우, 눈토끼, 아기 설인 등 (자체 디자인)
  - 등급: 일반 / 희귀 / 영웅 / 전설 / 오로라(반짝이)
  - 따라다니며 코인 배수, 낚시 확률 등 효과
  - 같은 펫 3마리 합치면 상위 등급
- **장비 강화**: 썰매·스키 속도, 회전, 점프력
- **구역 해금**: 코인으로 상급 슬로프, 얼음 호수, 오로라 봉우리
- **순위표**: 일간·주간 리셋으로 누구나 1등 기회
